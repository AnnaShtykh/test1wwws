Setup Guide

Getting started with your {{COMPANY_NAME}} brand system

This guide walks you through setting up the tools we built so anyone on your team can create on-brand content — no design or technical background needed. It should take about ten minutes.

You received two things: a Skill and a Project. Both teach an AI assistant your brand's colors, fonts, voice, and rules, so it applies them automatically whenever you ask it to write or design something. Each one works in both Claude and ChatGPT — set up whichever you actually use, or all of them.

1Setting up the Skill

Install this once, in whichever product you use — it then works automatically in every new chat, with no extra setup.

In Claude
  1. Go to claude.ai and sign in (or open the Claude desktop app).
  2. Go to the left sidebar and click on Customize → Skills.
  3. On the popup that opens, click the + button (top right corner), then "Upload a skill".
  4. Choose the file {{SLUG}}-skill.zip that we delivered to you.
  5. Once it appears in your list, switch it on.
Once it's on, it works everywhere in Claude — Claude Chat, Claude Code, Claude Design, and Claude Cowork.
In ChatGPT
  1. In ChatGPT, click Plugins in the left sidebar.
  2. Click the Skills tab at the top of the window that opens.
  3. Click the + button in the top right corner.
  4. Click "Upload from your computer" and choose the same file {{SLUG}}-skill.zip.
  5. Once it finishes uploading, it's ready to use.
In ChatGPT, this only works in Work mode and in Codex — not in a regular chat.
How to use it? Just mention {{COMPANY_NAME}} — or, to be sure it's applied, tag it directly: /{{SLUG}}-skill in Claude, @{{SLUG}}-skill in ChatGPT.

2Setting up the Project

Claude and ChatGPT each have their own "Project" feature, set up almost the same way.

In Claude
  1. Go to claude.ai and sign in.
  2. Click Projects in the left sidebar, then Create project, and name it "{{COMPANY_NAME}} Brand".
  3. Open {{SLUG}}-project/instructions.md that we delivered, copy all of its text, and paste it into the project's instructions box.
  4. Open the {{SLUG}}-project/Sources folder and upload every file inside it to the project.
In ChatGPT
  1. Go to chatgpt.com and sign in.
  2. Click Projects in the left sidebar, then New project, and name it "{{COMPANY_NAME}} Brand".
  3. On the project's page, click the ••• button in the top right corner.
  4. A "Project settings" window pops up. Inside it, find the Instructions box and paste in the same instructions.md text.
  5. Still on the project's page, click the Sources tab, and upload every file inside the {{SLUG}}-project/Sources folder there.

How to use it? Start a new chat from inside the project — your brand rules are applied automatically, no need to repeat them.
